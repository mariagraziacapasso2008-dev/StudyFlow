# 📚 StudyFlow – Diario Digitale per Studenti

## 📌 Descrizione
StudyFlow è una web application che funziona come diario digitale per studenti. Permette di organizzare compiti, eventi scolastici e orario delle lezioni, oltre a includere un timer Pomodoro per la gestione del tempo di studio.

---

## ⚙️ Funzionalità
- Login e gestione utente
- Task manager (compiti)
- Calendario con eventi e orari
- Timer Pomodoro con pausa e focus
- Orario scolastico personalizzato in tabella

---

## 💻 Tecnologie utilizzate
- HTML
- CSS
- JavaScript
- Python (Flask)
- SQLite

---

## ▶️ Avvio del progetto

Installa le dipendenze:
pip install Flask

Avvia il server:
python app.py

Apri nel browser:
http://127.0.0.1:5000
