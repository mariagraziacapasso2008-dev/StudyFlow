# StudyFlow
Il capolavoro “StudyFlow” è una web application pensata come diario digitale per studenti. Permette di organizzare compiti, eventi e orario scolastico, e include strumenti utili allo studio come un timer Pomodoro. L’obiettivo è aiutare gli studenti a gestire meglio il tempo e le attività scolastiche in modo semplice e digitale.
